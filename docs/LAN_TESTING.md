# AIS3 Junior 作業繳交系統 — 內網測試指南（不建立對外連線）

這份指南說明如何在**完全不對外**的環境下測試 AAMS：先在單機測試，再讓同一個區域網路（或一台獨立的路由器／交換器）裡的其他電腦、手機連進來，最後跑完驗收劇本與壓力測試。

> ⚠ 內網測試預設使用 **HTTP**，帳號密碼會以明文在區網中傳輸。**只用示範帳號（`@demo.ais3.local`）測試，不要匯入真實學員資料**。真實資料一律走 HTTPS + WireGuard（見 BUILD_AND_USAGE.md §6），或至少使用本文 §4 的區網 HTTPS。

---

## 1. 網路環境建議

| 方式 | 適用 | 說明 |
|---|---|---|
| A. 單機 | 開發者自己測 | 只監聽 `127.0.0.1`，最安全 |
| B. 獨立路由器／交換器（不接 WAN） | 多人實機測試（建議） | 一台沒有接外網的路由器，伺服器與測試電腦都接上去；天然隔離外網 |
| C. 既有辦公室／學校區網 | 快速多人測試 | 用 Windows 防火牆限制只允許本機子網路連入，測完即關閉 |

本系統執行時**完全不需要網際網路**：所有 CSS／JS／背景圖都在本機 `aams/static/`，不載入任何 CDN。只有「安裝 Python 套件」那一步需要網路（或事先下載 wheel，見 BUILD_AND_USAGE.md §3.1）。

## 2. 單機測試（方式 A）

```powershell
cd D:\AIS3J-homework-system
.\.venv\Scripts\python manage.py init                  # 已有 .env 會略過
.\.venv\Scripts\python manage.py seed-demo --active    # 第一次才需要
.\.venv\Scripts\python run.py
```

瀏覽器開 <http://127.0.0.1:8000>。想重新開始：停止 `run.py` → 刪除 `data\` 資料夾 → 重新 `seed-demo`。

要測「首次登入強制改密碼」流程時，用 `seed-demo`（不加 `--active`），所有帳號密碼都是 `10007038907`。

## 3. 多台電腦連線（方式 B／C）

### 3.1 伺服器端設定

1. 產生允許區網連線的設定（若已有 `.env`，把 `AAMS_HOST` 改為 `0.0.0.0` 即可）：

   ```powershell
   .\.venv\Scripts\python manage.py init --lan --force
   ```

   > `--force` 會產生新的 SECRET，既有登入 Session 與已綁定的 TOTP 會失效。測試環境沒關係；若不想重設，直接手動編輯 `.env` 的 `AAMS_HOST=0.0.0.0`。

2. 查伺服器的區網 IP：

   ```powershell
   ipconfig
   # 找「IPv4 位址」，例如 192.168.50.10
   ```

3. 開 Windows 防火牆（**以系統管理員身分**開 PowerShell），只允許本機子網路連 8000/8001：

   ```powershell
   New-NetFirewallRule -DisplayName "AAMS LAN test" -Direction Inbound -Protocol TCP `
     -LocalPort 8000,8001 -RemoteAddress LocalSubnet -Action Allow -Profile Private,Domain
   ```

   網路設定檔若是「公用」，請在「設定 › 網路和網際網路 › 內容」改成「私人」，或在指令加上 `Public`。

4. 啟動：

   ```powershell
   .\.venv\Scripts\python run.py
   ```

### 3.2 用戶端（其他電腦／手機）

- 開瀏覽器到 `http://192.168.50.10:8000`（換成伺服器 IP）。
- **8001 port 也必須能連**：PDF 預覽是從 `http://192.168.50.10:8001` 這個獨立來源載入的（安全隔離設計）。如果作業頁能開、但「預覽」是空白，十之八九是 8001 被防火牆擋住。
- 手機會顯示桌面版（規格：桌面優先），可縮放操作。

### 3.3 連線檢查

在用戶端電腦的 PowerShell：

```powershell
Test-NetConnection 192.168.50.10 -Port 8000
Test-NetConnection 192.168.50.10 -Port 8001
curl.exe -s http://192.168.50.10:8000/healthz      # 應回 ok
```

### 3.4 測試結束後

```powershell
Remove-NetFirewallRule -DisplayName "AAMS LAN test"
```

並把 `.env` 的 `AAMS_HOST` 改回 `127.0.0.1`。

## 4.（選用）區網 HTTPS 測試

想在區網裡也驗證 HTTPS、Secure Cookie 與憑證信任鏈（規格 SEC-014），可在伺服器上用 Caddy（單一執行檔，離線可用；需事先從 <https://caddyserver.com/download> 下載 Windows 版 `caddy.exe`）：

1. 建立 `Caddyfile.lan`（IP 換成你的伺服器 IP）：

   ```caddyfile
   {
   	admin off
   }
   https://192.168.50.10:443 {
   	tls internal
   	request_body {
   		max_size 45MB
   	}
   	reverse_proxy 127.0.0.1:8000
   }
   https://192.168.50.10:8443 {
   	tls internal
   	reverse_proxy 127.0.0.1:8001
   }
   ```

2. `.env` 改為：

   ```ini
   AAMS_HOST=127.0.0.1                     # 只讓 Caddy 連 app
   AAMS_COOKIE_SECURE=true
   AAMS_PREVIEW_URL=https://192.168.50.10:8443
   ```

3. 防火牆改開 443、8443（關掉 8000/8001），啟動 `run.py` 與 `caddy run --config Caddyfile.lan`。
4. 把 Caddy 根憑證（Windows：`%AppData%\Caddy\pki\authorities\local\root.crt`）複製到測試電腦，匯入「受信任的根憑證授權單位」。
5. 用戶端開 `https://192.168.50.10`。

## 6. 壓力測試（規格 §9.3 #14）

模擬截止前 72 人同時交件。需要另一台電腦（或同一台）執行，伺服器需用 `seed-demo --active` 的示範資料。

所有請求都從同一個 IP 發出，會觸發「每 IP 登入次數」限制，所以壓測時暫時在伺服器 `.env` 加上：

```ini
AAMS_LOGIN_IP_LIMIT=500
```

（壓測完請刪除，回復預設 60。）重新啟動 `run.py` 後執行：

```powershell
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
# 72 人 × 19.5 MB（20 MB 額度的個人作業）
.\.venv\Scripts\python tools\load_test.py --base http://192.168.50.10:8000 --mb 19.5
# 12 組 × 35 MB 拆 2 檔（40 MB 額度的團體作業）；每組只派 1 人
.\.venv\Scripts\python tools\load_test.py --base http://192.168.50.10:8000 --assignment Crackme --mb 35 --files 2 --users 12
```

> `--users 12` 會取前 12 位學員（第 1、2 組各 6 人），所以同組會有多個版本並觸發 5 版淘汰；這是預期行為，最舊的版本會顯示「已依只保留 5 版規則淘汰」。

開發機（本機迴路、SQLite）實測參考值：72 人 × 19.5 MB **72/72 成功收據，總耗時約 11.6 秒**，單次中位數 3.9 秒；檔案檢查佇列約 20 秒內消化完畢。**這只是開發機數字，不能代表正式主機**；請在目標硬體、實際網路（WireGuard）上重測，並記錄：

- 成功收據比例（應 100%）
- 單次提交耗時中位數／最大值
- 管理後台「檢查中」歸零所需時間
- `data\` 磁碟用量增加量（72 × 19.5 MB ≈ 1.4 GB）

## 8. 常見問題

| 狀況 | 原因／處理 |
|---|---|
| 其他電腦連不到 | `.env` 的 `AAMS_HOST` 不是 `0.0.0.0`；防火牆未開；網路設定檔是「公用」；伺服器與用戶端不在同一網段 |
| 作業頁正常，但預覽空白 | 8001 被擋；或使用 HTTPS 時 `AAMS_PREVIEW_URL` 沒設成 `https://…:8443` |
| 一直卡在「檢查中」 | 看 `run.py` 視窗的錯誤；確認 `.venv` 內有 `pypdf`；檢查失敗一律 fail-closed（不會放行） |
| 登入顯示「嘗試次數過多」 | 同一 IP 5 分鐘內登入超過上限；等 5 分鐘或重啟 `run.py`（計數在記憶體中） |
| 管理員進不了後台 | 必須先綁定 TOTP；手機時間要準確；測試時可用 `manage.py totp-code` |
| 上傳大檔回 413 | 合計超過作業設定或系統 40 MB 上限，屬預期行為 |
| 中文在命令列顯示亂碼 | 用 Windows Terminal／PowerShell，或先執行 `$env:PYTHONIOENCODING="utf-8"` |
| 想完全重來 | 停止 `run.py` → 刪除 `data\` → `manage.py seed-demo --active` |
